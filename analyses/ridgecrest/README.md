# Ridgecrest analysis

This directory contains the empirical temporal ETAS analysis of the 2019 Ridgecrest earthquake sequence using the Omori–Utsu (OU), modified stretched exponential (MSE), and rate-state (RS) temporal decay forms.

The analysis uses the derived Ridgecrest catalogue in `data/derived/` and applies the same baseline priors and numerical settings used in the simulation study.

## Workflow

Scripts are numbered in their intended order:

| Script | Purpose | Compute note |
|------------------|------------------------------------|------------------|
| `00_design.R` | Defines Ridgecrest output paths and imports the shared simulation fitting design | Sourced automatically by other scripts |
| `01_fit_baseline.R` | Fits OU, MSE and RS to the baseline Ridgecrest catalogue | 3 fits, \~30 MB |
| `02_posterior_parameters.R` | Produces posterior parameter summaries and figures | Requires baseline fits from `01` |
| `03_temporal_functions.R` | Evaluates and plots posterior temporal decay functions | Requires baseline fits from `01` |
| `04_model_comparison.R` | Log-marginal-likelihood comparison of the three baseline models | Requires baseline fits from `01` |
| `05_m0_sensitivity.R` | Repeats fitting at alternative magnitude thresholds | **\~20–30 min, \~60 MB of fits** |
| `05a_convergence_issues.R` | Diagnoses non-converged magnitude-sensitivity fits | Requires fits from `05` |
| `06_prior_sensitivity.R` | Assesses sensitivity to alternative MSE and RS priors | 2 fits, \~20 MB |

Runtime estimates are shown only for the more computationally demanding stages. They were recorded on the Apple M4 MacBook Air used for the dissertation analysis and will vary with hardware and system configuration.

## Fitted-model objects

Large fitted-model `.rds` files beneath `fits/` directories are intentionally excluded from Git because they are reproducible intermediate files and would add unnecessary storage overhead. Individual fitted-model objects are typically around 10 MB.

The repository instead retains the fitting manifests, summaries, tables and figures documenting the original analysis.

Scripts `02`–`04` require the three baseline fitted-model objects generated by `01_fit_baseline.R`. The sensitivity analyses similarly require their corresponding fit objects when downstream diagnostics are rerun.

## Reproducing the Ridgecrest analysis

The analysis uses `data/derived/ridgecrest_temporal_catalogue.rds`, which is produced by the Ridgecrest EDA in `analyses/eda/eda_ridgecrest.qmd`.

To reproduce the complete workflow from the raw earthquake catalogue, first run the EDA to regenerate the derived catalogue.

After the three baseline fits have been regenerated, scripts `02`–`04` reproduce the posterior parameter, temporal-function and model-comparison analyses.

`05_m0_sensitivity.R` and `05a_convergence_issues.R` reproduce the magnitude-threshold sensitivity analysis, while `06_prior_sensitivity.R` reproduces the prior-sensitivity analysis.

Software versions used for the dissertation analysis are recorded in `outputs/session_info.txt`.

The shared fitting helpers are in `src/fit_helpers/`, and the modified temporal ETAS implementation is provided in the `software/ETAS.inlabru` submodule.
