# Outputs

This directory contains generated outputs from the exploratory analysis, simulation study, Ridgecrest analysis, and initial temporal-decay comparison.

Most compact outputs used to document the dissertation analysis are retained in Git, including figures, tables, manifests, diagnostics, and synthetic catalogues.

## Directory structure

### `eda/`

Contains figures and summaries produced by the Ridgecrest exploratory data analysis in `analyses/eda/`.

### `simulation/`

Contains outputs from the simulation study in `analyses/simulation/`.

Key subdirectories are:

- `catalogues/` — the final 300 synthetic catalogues and simulation manifest
- `pilots/` — pilot catalogues, validation outputs, and numerical calibration results
- `fits/` — retained production fit metadata; large fitted-model objects are excluded
- `design_figures/` — figures describing the fixed simulation design
- `prior_calibration/` — prior-calibration summaries and figures
- `analysis/convergence/` — convergence, iteration, and runtime summaries
- `analysis/misspecification_diagnostics/` — targeted numerical diagnostics for difficult misspecified fits
- `analysis/parameter_recovery/` — parameter, functional-recovery, and posterior-dependence outputs
- `analysis/misspecification/` — temporal-form misspecification outputs
- `analysis/model_discrimination/` — DIC and log-marginal-likelihood model-comparison outputs

### `ridgecrest/`

Contains outputs from the empirical Ridgecrest analysis in `analyses/ridgecrest/`.

Key subdirectories are:

- `baseline/` — baseline OU, MSE, and RS analysis outputs
- `baseline/fit_summary/` — retained baseline fit manifest and diagnostics
- `baseline/parameters/` — posterior parameter summaries and figures
- `baseline/temporal_functions/` — posterior temporal-function summaries and figures
- `baseline/model_comparison/` — baseline model-comparison outputs
- `sensitivity/magnitude/` — magnitude-threshold sensitivity results
- `sensitivity/prior/` — prior-sensitivity results

### `comparison-figure/`

Contains the conceptual comparison figure for the three temporal decay forms.

### `session_info.txt`

Records the software environment used for the dissertation analysis.

## Fitted-model objects

Large fitted-model `.rds` files beneath `fits/` directories are intentionally excluded from Git because they are reproducible intermediate files and would add substantial storage overhead.

Individual fitted-model objects are typically around 10 MB, while the full simulation study generates approximately 10–12 GB of production fits.

The corresponding fitting scripts recreate these files locally when required.

Compact records of the original fitting runs, such as fit manifests, indices, diagnostics, summaries, tables, and figures, are retained in the repository.

## Simulation fitted models

The 900 production fitted-model objects generated by `analyses/simulation/06_fit_simulation.R` are excluded from Git.

The following metadata are retained under `outputs/simulation/fits/`:

- `fit_index.csv`
- `fit_manifest.csv`
- `problem_fits.csv`
- `run_design.rds`

The final 300 synthetic catalogues are retained under `outputs/simulation/catalogues/`, allowing the production fitting stage to be reproduced without regenerating the synthetic data.

## Ridgecrest fitted models

Baseline, magnitude-sensitivity, and prior-sensitivity fitted-model objects are also excluded from Git.

Their corresponding manifests, summaries, diagnostics, tables, and figures are retained under `outputs/ridgecrest/`.

The relevant fitting scripts in `analyses/ridgecrest/` can be rerun when the omitted fitted-model objects are required.
