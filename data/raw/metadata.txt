================================================================================
METADATA
Project: A temporal Bayesian ETAS analysis of the 2019 Ridgecrest earthquake 
sequence: comparing the Omori-Utsu and alternative aftershock decay functions

This file describes the raw dataset in this directory: what it contains and how
to interpret it, the variables recorded (with units), when it was acquired, and 
where it came from.

--------------------------------------------------------------------------------
SUMMARY
--------------------------------------------------------------------------------

This dataset is an EARTHQUAKE CATALOGUE: a table with one row per detected
seismic event, recording when and where each event occurred, how large it was,
and how well its location and size were measured.

--------------------------------------------------------------------------------
FILE FORMAT
--------------------------------------------------------------------------------

Plain text, whitespace-delimited. The file begins with several non-data lines 
(a title line, an html "<PRE>" tag, and a DOI line) and ends with a "</PRE>" tag.
Data rows are the lines beginning with a date (YYYY/MM/DD); a commented header 
line precedes them. To read, keep only the date-initial lines and apply the 
column names below (see `src/read_catalogue.R`).

--------------------------------------------------------------------------------
VARIABLES
--------------------------------------------------------------------------------
Column header row in the raw files:
  #YYY/MM/DD  HH:mm:SS.ss  ET  GT  MAG  M  LAT  LON  DEPTH  Q  EVID  NPH  NGRM

(Definitions per the SCEDC catalog format specification, revised 2019-12-12, 
available at https://scedc.caltech.edu/eq-catalogs/catalog-search-help.html and 
https://scedc.caltech.edu/eq-catalogs/docs/scec_dc.html)

YYY/MM/DD  : date of the event.                             (calendar date)
HH:mm:SS.ss: time of the event, to hundredths of a second.  (time of day)
             Time is UTC (7 hours ahead of Pacific Daylight 
	     Time, 8 hours ahead of Pacific Standard Time).
ET         : event type.                                    (code, unitless)
             eq = earthquake, ex = explosion (unknown cause), 
	     sh = explosion (part of seismic survey),
	     qb = quarry blast, sn = sonic boom,
	     st = subnet trigger (detected by network 
             algorithm), th = thunder,
	     nt = nuclear blast, uk = unknown.
GT         : geographical type.                             (code, unitless)
             l = local (within SCSN region), 
	     r = regional (neighbouring network), 
	     t = teleseismic event (>1000 km away).
MAG        : magnitude value of the event.                  (magnitude units)
M          : type of magnitude that produced MAG.           (code, unitless)
             e = energy, w = moment, b = body-wave, 
	     s = surface-wave, l = local (Wood-Anderson), 
	     lr = revised local, c = coda amplitude, 
	     h = helicorder (short-period Benioff),
             d = coda duration, n = no magnitude.
LAT        : latitude of the epicentre.                     (decimal degrees,
                                                                    + = north)
LON        : longitude of the epicentre.                    (decimal degrees,
                                                                    - = west)
DEPTH      : hypocentral depth (between Earth's surface     (kilometres)
             and the exact point underground where the 
	     event originated), positive downward, 
	     measured relative to WGS84 reference ellipsoid.                
Q          : reliability of the estimated event location.   (grade, unitless)
             Formal horizontal/depth uncertainty of the 
	     computed hypocentre.
	     A = +-1 km horizontal, +-2 km depth;
             B = +-2 km horizontal, +-5 km depth;
             C = +-5 km horizontal, no depth restriction;
             D = worse than +-5 km horizontal;
             Z = no quality listed in database.
EVID       : SCEDC unique event identifier.		    (unitless)
NPH        : number of picked phases used in locating the   (count)
	     event.         
NGRM       : number of seismogram traces associated with    (count)
	     the event.
